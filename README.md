## 🧠 Overview

**Exam02** is a timed 42 project that tests your knowledge of **C fundamentals, algorithmic thinking, and problem-solving under pressure**.  

The goal is to solve specific coding exercises or challenges in a limited timeframe, focusing on **efficiency, code readability, and adherence to the Norminette style guide**.  

This exam helps reinforce all the foundational C concepts learned so far and prepares students for more advanced projects.

---

## 🧩 Key Objectives

- Apply knowledge of **pointers, arrays, and memory management**  
- Solve problems under strict time constraints  
- Write **clean, Norminette-compliant code**  
- Develop efficient and modular solutions  
- Strengthen debugging and testing skills
